# Central de Regulação — Módulo Ambulatorial (demo)

Demonstração de um sistema de regulação ambulatorial com dados **fictícios**.
É um arquivo único: abra `index.html` no navegador. Os dados ficam salvos no
`localStorage` do navegador ("Restaurar dados de exemplo", no menu lateral, volta ao início).

## Telas

| Área | Telas |
|---|---|
| Início | Painel com indicadores, próximos atendimentos, fila de regulação, ocupação, prazos judiciais e atividade recente |
| Atendimento | Recepção (chegada, falta, finalizar), Agenda do dia (por profissional, com horários livres), Faltas (contato e reagendamento) |
| Agendamento | Novo agendamento (assistente em 4 etapas + comprovante), Encaixe, Troca de paciente |
| Regulação | Demandas por recurso (fila com prioridade), Solicitações externas, Ações judiciais |
| Cadastros | Pacientes (busca, ficha, histórico), Profissionais (escala, ocupação, bloqueio de agenda) |
| Gestão | Relatórios (indicadores, gráfico, CSV, impressão), Ajuda e suporte |

Outros recursos: busca global (Ctrl+K), central de pendências, tema claro/escuro e layout responsivo.
