# Regulação Ambulatorial (demo)

Recriação do layout de um sistema de regulação ambulatorial, com marca e dados fictícios.
É um arquivo único: abra `index.html` no navegador. Os dados ficam salvos no `localStorage`
do navegador (Manutenção → Restaurar dados de exemplo para zerar).

Telas: Agenda (Paciente / Seleção / Agenda Interna / Agenda Externa), Cadastro Demanda por
Recurso (Inserir / Listar), Agenda Diária, Recepção, Ausentes, Cadastro de Paciente,
Agenda dos Profissionais, Consulta e Relatório por período.
